1. RESUMEN EJECUTIVO
--------------------------------------------------------------------------
La sesión introduce la teoría de dualidad en programación lineal: todo
problema de maximización (primal) tiene asociado un problema de minimización
(dual) construido con los mismos datos, y ambos comparten el mismo valor óptimo.

Para consolidar la idea, la clase resuelve un ejemplo completo: se plantea el
primal, se construye su dual y se resuelve el dual con el método simplex usando
una variable artificial (método de la M grande). Al final se recupera la
solución del primal a partir de la tabla óptima del dual.

Resultado del ejemplo: el valor óptimo es 11/2 para ambos problemas, con
solución primal x1 = 3/2, x2 = 0, x3 = 1/2.


2. CONCEPTOS CLAVE
--------------------------------------------------------------------------
Agenda en la pizarra: Simplex PPL (estándar), variables artificiales y
min-dualidad.

* Primal (forma estándar)
  Max Z = c1x1 + ... + cnxn, sujeto a Ax <= b y x >= 0, con A de tamaño m x n.

* Dual
  Min Z~ = b1y1 + ... + bmym, sujeto a A^T y >= c y y >= 0. Aquí m es el número
  de restricciones del primal.

* Regla de transformación
  Los coeficientes b pasan a ser la función objetivo del dual; los c pasan al
  lado derecho de las restricciones; la matriz A se transpone y se cambia <=
  por >=.

* Relación entre óptimos
  Min(Z~) = Max(Z). El valor óptimo del dual coincide con el del primal
  (recuadro final de la pizarra).

* Min a Max
  Min(Z~) = -Max(-Z~). Sirve para poder aplicar simplex, que se plantea como
  maximización.

* Variables de holgura/exceso
  Convierten las desigualdades en igualdades (s1, s2, s3 >= 0).

* Variable artificial
  Cuando la variable de exceso queda negativa (aquí s1 = -4, no factible), se
  añade t1 >= 0 para tener una base inicial factible.

* Método de la M grande
  La función objetivo artificial W = -Z~ - M*t1 penaliza a t1. Antes de iterar
  hay que eliminar M de la columna de t1 (operación R4 - M*R1).


3. EJEMPLO RESUELTO PASO A PASO
--------------------------------------------------------------------------

3.1 Problema primal

    Max Z = 4x1 - x2 - x3
    sujeto a:  3x1 + x2 - x3 <= 4
                x1 + x2 + x3 <= 2
                x1, x2, x3 >= 0

    Matriz de restricciones: A = [[3, 1, -1], [1, 1, 1]]  (2 x 3)

3.2 Construcción del dual

Se transpone A y se intercambian los papeles de b = (4, 2) y c = (4, -1, -1):

    Min Z~ = 4y1 + 2y2
    sujeto a:   3y1 + y2 >= 4
                 y1 + y2 >= -1
                -y1 + y2 >= -1
                y1, y2 >= 0

El profesor anota que, al tener solo dos variables, este dual también podría
resolverse con el método gráfico. Se elige simplex para practicar la variable
artificial.

3.3 Forma estándar y variable artificial

- Se pasa a maximización: Min(Z~) = -Max(-Z~), con Max(-Z~) = -4y1 - 2y2.
- Se agregan variables de holgura y exceso s1, s2, s3 >= 0. La primera
  restricción queda 3y1 + y2 - s1 = 4; las otras dos se multiplican por -1
  para tener lado derecho positivo.
- Con y = 0 resulta s1 = -4, que no es factible. Por eso se incluye la variable
  artificial t1 >= 0 en la primera restricción.
- Función objetivo artificial: W = -Z~ - M*t1, es decir, Z~ + M*t1 + W = 0.

3.4 Tabla inicial (M ya eliminada de la columna de t1)

Tras R4 - M*R1, la fila de W queda con 4-3M en la columna de y1, el valor más
negativo para M grande. Entra y1; por la razón mínima (1/1 frente a 4/3) sale
s3, con pivote 1.

  Base |  y1    y2    s1   s2   s3   t1   W    R
  -----+---------------------------------------------
  t1   |  3     1    -1    0    0    1    0    4
  s2   | -1    -1     0    1    0    0    0    1
  s3   |  1    -1     0    0    1    0    0    1
  W    | 4-3M  2-M    M    0    0    0    1   -4M

3.5 Primera iteración

Operaciones: R1 - 3R3, R2 + R3 y R4 - (4-3M)R3. Ahora y1 es básica. En la fila
W el valor 6-4M en la columna de y2 sigue siendo negativo, así que entra y2 y
sale t1 (única entrada positiva de la columna).

  Base |  y1    y2    s1   s2    s3    t1   W    R
  -----+------------------------------------------------
  t1   |  0     4    -1    0    -3     1    0    1
  s2   |  0    -2     0    1     1     0    0    2
  y1   |  1    -1     0    0     1     0    0    1
  W    |  0    6-4M   M    0   -4+3M   0    1   -4-M

3.6 Segunda iteración y tabla óptima

Operaciones: (1/4)R1, R2 + 2R1, R3 + R1 y R4 - (6-4M)R1. Al salir t1 de la
base, los términos con M se cancelan (por ejemplo, M - (6-4M)(-1/4) = 3/2). La
columna de t1 se descarta y W se reemplaza por -Z~.

  Base |  y1   y2    s1    s2    s3    -Z~    R
  -----+------------------------------------------
  y2   |  0    1   -1/4    0   -3/4    0     1/4
  s2   |  0    0   -1/2    1   -1/2    0     5/2
  y1   |  1    0   -1/4    0    1/4    0     5/4
  -Z~  |  0    0    3/2    0    1/2    1   -11/2

Todos los coeficientes de la fila objetivo son no negativos, por lo que la
tabla es óptima.

3.7 Solución

- Solución del dual:       y1 = 5/4, y2 = 1/4, s2 = 5/2
- Valor óptimo del dual:   Max(-Z~) = -11/2, por lo tanto Min(Z~) = 11/2
- Valor óptimo del primal: Max(Z) = 11/2 (por dualidad, Min Z~ = Max Z)
- Solución del primal:     x1 = 3/2, x2 = 0, x3 = 1/2 (se leen en la fila
                           objetivo, bajo s1, s2 y s3)

Verificación rápida:
  Primal: 3(3/2) + 0 - 1/2 = 4 <= 4 y 3/2 + 0 + 1/2 = 2 <= 2,
          con Z = 4(3/2) - 0 - 1/2 = 11/2.
  Dual:   3(5/4) + 1/4 = 4 y -5/4 + 1/4 = -1 (ambas activas),
          con Z~ = 4(5/4) + 2(1/4) = 11/2.
  Los dos valores coinciden.

  33 - 40      Segunda iteración y cálculos con M hasta la tabla óptima (-11/2).

  44 - 47      Cierre con la vista general de la dualidad y el recuadro
               Min(Z~) = Max(Z).


5. PUNTOS PARA ESTUDIAR Y REPASAR
--------------------------------------------------------------------------
- Construir el dual sin errores: transponer A, intercambiar b y c, y cambiar el
  sentido de las desigualdades.
- Saber cuándo hace falta una variable artificial y cómo se penaliza con M.
- Recordar siempre eliminar M de la columna de la artificial antes de elegir la
  columna pivote.
- Elegir la columna pivote con el coeficiente más negativo en la fila objetivo
  (considerando M grande) y la fila con razón mínima positiva.
- Convertir el resultado: el óptimo de Min(Z~) es el negativo del óptimo de
  Max(-Z~), y coincide con el Max(Z) del primal.
- Ejercicio sugerido: resolver el mismo dual con el método gráfico y confirmar
  que el punto óptimo es (5/4, 1/4).
